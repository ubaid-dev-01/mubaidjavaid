## Overview

Portfolio site for M Ubaid Javaid: selected work, Evolvo delivery gallery, writing, and contact. Next.js + GSAP with a carefully designed SVG/asset system.

## Features

- Case study pages
- Evolvo delivery gallery
- Writing index
- Contact API route
- Brand SVG system

## Architecture

App Router portfolio with static assets under `assets/` and content under `data/` / `docs/`.

## Tech stack

- Next.js
- React
- TypeScript
- GSAP
- Tailwind CSS
- TanStack Query

## Project structure

```text
mubaidjavaid/
├── app/ assets/ components/ data/ docs/ lib/
└── public/
```

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Environment

`NEXT_PUBLIC_SITE_URL`, Resend, GA4 as needed — see `.env.example`.
